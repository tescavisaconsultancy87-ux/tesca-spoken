# Project: TESCA Spoken English — High-Converting Meta Ads Landing Page

## 1. Executive Overview
- **Brand**: TESCA VISA CONSULTANCY & SPOKEN ENGLISH (Trusted educational institute since 2005).
- **Product**: Premium Online Spoken English Course accessible via mobile and the Class Plus App.
- **Audience**: Students, job seekers, working professionals, homemakers, and anyone desiring real-world English speaking confidence.
- **Conversion Goal**: Drive high-converting qualified Meta Ads traffic to purchase the course via the Class Plus App integration or download.
- **Customer Journey**:
  `Meta Ad → Dedicated High-Conversion Landing Page → Problem Identification → Solution & Curriculum Clarity → Trust & Social Proof → Primary CTA Click → Class Plus App / Checkout → Course Purchase`

## 2. Core Value Proposition
- "Speak English With Confidence. Without Fear. Without Hesitation."
- Moving from memorizing rigid grammar to speaking practical everyday English.
- Learn at your own pace, anytime, directly on mobile with structured lessons.

## 3. Tech Stack & Architecture
- **Framework**: Next.js 16 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4, custom HSL color tokens, dark navy & vibrant blue with high-contrast warm CTA
- **Motion & Interactions**: GSAP 3 (ScrollTrigger, micro-interactions, staggered entrances) + Framer Motion
- **Tracking & Analytics**: Meta Pixel (PageView, ViewContent, Lead, InitiateCheckout, Custom Events), Google Analytics / GTM, PostHog
- **Platform Access**: Class Plus App direct links & deep linking
